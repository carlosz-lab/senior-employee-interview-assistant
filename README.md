# 中高齡員工訪談助手（Senior Employee Interview Assistant）

這是一個針對餐飲業「中高齡員工職務再設計」專案所開發的訪談輔助工具。

👉 透過結構化訪談 + 員工與店長認知落差比對  
👉 協助管理者快速掌握現場問題本質與潛在風險

---

## 🔗 線上使用

👉 https://carlosz-lab.github.io/senior-employee-interview-assistant/

（GitHub Pages 開啟後可使用）

---

## 🎯 使用情境

- 門市員工訪談
- 店長訪談
- 中高齡員工適應狀況評估
- 管理問題診斷（訓練 / 溝通 / 工作設計）

---

## 🧩 功能特色

- 員工訪談紀錄
- 店長訪談紀錄
- 員工 vs 店長認知落差比對
- PDF 報告匯出（給主管閱讀）
- AI 分析資料輸出（給 ChatGPT / Claude 分析）
- JSON 備份與還原
- Demo 資料載入

---

## 🧠 工具設計邏輯

本工具將訪談內容拆解為六大模組：

- M1 工作站負荷
- M2 學習與導入
- M3 生理負荷
- M4 公平知覺
- M5 跨世代關係
- M6 綜合回饋

透過雙方回答對照，快速識別：

👉 認知落差  
👉 管理問題  
👉 潛在風險  

---

## 🧾 使用流程

1. 填寫員工訪談
2. 填寫店長訪談
3. 進入「落差比對 ＆ 分析」
4. 匯出 PDF（給主管）
5. 複製 AI 分析資料（進行深度分析）
6. 匯出 JSON 備份

---

## ⚠️ 資料儲存說明（重要）

本工具為純前端應用：

- 資料僅儲存在「使用者瀏覽器」
- 不會上傳至任何雲端
- 不會跨裝置同步

👉 請務必定期匯出 JSON 備份資料

---

## 💡 專案背景

在實際門市訪談中發現：

- 員工與主管對同一件事情的認知差異很大
- 問題常被誤判為「人」，實際上是「制度或設計」
- 缺乏一個結構化工具來快速整理與判斷

因此開發本工具，將訪談 → 比對 → 分析流程系統化。
